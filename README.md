# Conecta Check-in — atualizações

Este repositório público distribui apenas os instaladores Windows e os metadados de atualização do Conecta Check-in.

Para instalar, abra **Releases** e baixe `Conecta-Check-in-Setup-1.1.0-x64.exe` (ou a versão mais recente). O executável portátil é opcional e não recebe atualização automática.

Após instalado, o app consulta novas versões e oferece a instalação; também há **Mais opções > Verificar atualizações**.
