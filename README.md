# Conecta Check-in — atualizações

Este repositório público distribui os instaladores Windows e os metadados de atualização do Conecta Check-in.

Para instalar, abra a versão mais recente em https://github.com/renezit0/conecta-checkin-updates/releases/latest e baixe `Conecta-Check-in-Setup-*-x64.exe`. O Setup instala o app e consulta futuras atualizações. O executável portátil é separado e não recebe instalação automática de updates.

No app instalado, use **Mais opções > Verificar atualizações** para consultar manualmente. Após baixar uma nova versão, o app oferece reiniciar e instalar.

O código-fonte fica no repositório privado do projeto; esta área pública contém apenas os arquivos necessários para instalação e atualização.
